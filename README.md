# [Data/Business Intelligence Analyst Portfolio](https://github.com/kagap)

## Introduction
Welcome to my portfolio. I am a Data/Business Intelligence Analyst skilled in SQL, Python, Tableau, PowerBI, Excel and BPMN. This repository is a compilation of the various projects I have worked on to sharpen my skills in data analysis, visualization and business processes modelling.

## Projects

### Data course series (Python → SQL → Statistics → Spark → Data Engineering)

1. [python-starter-pack](https://github.com/kagap/python-starter-pack): 10 interactive Jupyter Notebook modules covering Python from the basics through classes, regex, testing, and the Pandas/API capstone — in English and Polish.

2. [sql-](https://github.com/kagap/sql-): 14 interactive Jupyter Notebook modules covering SQL with PostgreSQL, from first queries through window functions, PL/pgSQL, and JSON — in English and Polish.

3. [statistic](https://github.com/kagap/statistic): 15 interactive Jupyter Notebook modules covering statistics for data analysis, from descriptive stats through regression and A/B testing — in English and Polish.

4. [pyspark](https://github.com/kagap/pyspark): 15 interactive Jupyter Notebook modules covering distributed data processing with Apache Spark and Databricks — in English and Polish.

5. [airflow](https://github.com/kagap/airflow): 9 interactive Jupyter Notebook modules covering data engineering — Apache Airflow, dbt, data warehouse modeling, and streaming with Kafka/Spark. In Polish.

### Other projects

6. [python_project](https://github.com/kagap/python_project): A Flask web app analyzing Polish wage/inflation data, plus a set of smaller Python data-visualization scripts and a Streamlit dashboard.

7. [python_study](https://github.com/kagap/python_study): Coursework notebooks from an Object-Oriented Python university course (classes, data structures, NumPy/Pandas exercises). In Polish.

8. [Tableau Projects](https://github.com/kagap/tableau_project): Tableau dashboards built on real-world datasets (coffee caffeine content, global EV market share, NCAA basketball rosters).

9. [Power BI Projects](https://github.com/kagap/powerbi): Six Power BI dashboards covering topics like cost of living, military spending, pizza sales, and social media trends.

10. [Kotlin_project](https://github.com/kagap/Kotlin_project): An Android coin-catching arcade game built in Kotlin, with local accounts and a leaderboard.

11. [BPMN Projects](https://github.com/kagap/bpmn): Business process models built with BPMN. In Polish.

Feel free to check out each repository for a deeper understanding of each project.
